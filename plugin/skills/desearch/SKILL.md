# Desearch

Version 0.10.0 exposes 51 tools.

Pick one Desearch tool from this list. Do not call a tool that is not registered.

Set `DESEARCH_API_KEY` before the server starts. The plugin launches `npx -y desearch-mcp-server` and passes that variable through. The search, X, TikTok, Facebook, Instagram, YouTube, Reddit, and Threads tools send read requests. They do not post, follow, delete, or change an account. `people-search` starts a billed background search, and `people-search-pause`, `people-search-resume`, and `people-search-cancel` pause, resume, or cancel one. `company-search` and `company-enrich` start billed background company tasks, and `company-search-pause`, `company-search-resume`, and `company-search-cancel` pause, resume, or cancel one. `monitor-create` sets up a monitor whose runs are billed, `monitor-trigger` runs one now (billed), `monitor-update` changes or pauses it, `monitor-delete` removes it, and `monitor-webhook-rotate-secret` replaces its webhook signing secret.

## Which tool

- **AI Search** (`ai-search`): Calls Desearch AI search. Arguments: `prompt` (required). `tools` is optional and defaults to `web` and `twitter`. Allowed `tools` values are `web`, `twitter`, `arxiv`, `wikipedia`, `hackernews`, and `reddit`. Older labels such as `Web Search`, `ArXiv Search`, `Wikipedia Search`, `Hacker News Search`, and `Reddit Search` are accepted and rewritten to the short id. `youtube` is not accepted. Optional: `date_filter`, `start_date`, `end_date` (UTC), `result_type` (`ONLY_LINKS` or `LINKS_WITH_FINAL_SUMMARY`), `include_domains`, `exclude_domains`, `model` (`NOVA` or `ORBIT`, default `NOVA`).
- **Search** (`search`): Web search that returns `results` with `id`, `title`, and `url`. Argument: `query` (required). Use this when a client asks for a search tool.
- **Fetch Page** (`fetch`): Read one public page as text. Argument: `id` (required, an `http` or `https` URL, usually a `search` result URL).
- **Web Search** (`web-search`): Web search. Returns titles, links, and snippets. Arguments: `query` (required), `start` (optional offset: 0, 10, 20, ...).
- **Search API** (`search-api`): Ranked web pages, each with the passage that best matches the query. Arguments: `query` (required), `mode` (optional, `fast` or `balanced`), `count` (optional, 10, 15, or 20), `start_date` and `end_date` (optional, YYYY-MM-DD), `highlights` (optional), `page_text` (optional, adds each page's full text).
- **Web Links Search** (`web-links-search`): Link search. Arguments: `prompt` (required), `tools` (optional, only `web`, default `["web"]`), `count` (optional, 10 to 200). `Web Search` is accepted and rewritten to `web`. Other sources are rejected. This tool does not accept X.
- **Extract** (`extract`): Read one public URL as text or HTML. Arguments: `url` (required), `format` (optional, `text`, `markdown` or `html`), `js` (optional), `wait` (optional milliseconds), `full_page` (optional, `text` only: every visible section of the page instead of its main content). Errors carry an `error_code`: `js_required` (retry with `js: true`), `blocked` (the site refused or showed a bot check), `page_not_found`.
- **Web Crawl** (`web-crawl`): Same arguments as Extract, on the legacy `/web/crawl` route. The SDK marks `webCrawl` deprecated in favor of `extract`. This tool stays so that route remains reachable.
- **X Search** (`x-search`): Search posts on X. Arguments: `query` (required), `count` (optional, default 20). Sort stays Top. Optional filters: `user`, `start_date`, `end_date` (YYYY-MM-DD), `lang`, `verified`, `blue_verified`, `is_quote`, `is_video`, `is_image`, `min_retweets`, `min_replies`, `min_likes`.
- **X Links Search** (`x-links-search`): Search for X post links. Arguments: `prompt` (required), `count` (optional, 10 to 200).
- **X Posts by URLs** (`x-posts-by-urls`): Posts for a list of post URLs. Argument: `urls` (required).
- **X Post by ID** (`x-post-by-id`): One post by ID. Argument: `id` (required).
- **X Posts by User** (`x-posts-by-user`): Posts by one user. Arguments: `user` (required), `query` (optional), `count` (optional, 1 to 100).
- **X User Posts** (`x-user-posts`): Posts from a username. Arguments: `username` (required), `cursor` (optional, from a previous response).
- **X User Replies** (`x-user-replies`): Posts and replies by one user. Arguments: `user` (required), `count` (optional, 1 to 100), `query` (optional).
- **X Post Replies** (`x-post-replies`): Replies to one post. Arguments: `post_id` (required), `count` (optional, 1 to 100), `query` (optional).
- **X Post Retweeters** (`x-post-retweeters`): Users who retweeted a post. Arguments: `id` (required), `cursor` (optional).
- **X Trends** (`x-trends`): Trends for a location WOEID. Arguments: `woeid` (required), `count` (optional, 30 to 100).
- **TikTok** (`tiktok`): Public TikTok data. `action` (required): `search` (`query`; optional `count`, `sort`, `cursor`), `post` (`id`), `profile` (`username`), `profile_posts` (`username`; optional `count`, `cursor`), `comments` (`video_id`; optional `count`, `cursor`), `hashtag` (`tag`; optional `count`, `cursor`), `trending` (optional `region`, `count`).
- **Facebook** (`facebook`): Public Facebook data. `action` (required): `search` (`query`) and `hashtag` (`tag`) return Meta Ad Library ads; `post` (`id`), `profile` (`profile_id`), `profile_posts` (`profile_id`), `comments` (`post_id`). List actions take optional `count` and `cursor`; `search` also takes `sort` (`impressions`, the default, or `recent` for recently started ads first).
- **Instagram** (`instagram`): Public Instagram data. `action` (required): `search` (`query`; optional `count`; no cursor), `media` (`id`), `profile` (`username`), `profile_posts` (`username`), `comments` (`shortcode` from the post URL), `hashtag` (`tag`). List actions take optional `count` and `cursor`.
- **YouTube** (`youtube`): Public YouTube data. `action` (required): `search` (`query`; optional `type`: `videos`, `shorts`, `channels`, `playlists`; `upload_date`: `today`, `this_week`, `this_month`, `this_year`; `sort_by`: `relevance`, `popular`; `duration`: `under_3_min`, `between_3_and_20_min`, `over_20_min`; `cursor`), `video` (`id`: video or Short ID or URL), `transcript` (`video_id`; optional `language` such as `en`; a video without captions returns 404), `comments` (`video_id`; optional `order`: `top`, `newest`; `cursor`), `channel` (`handle` with or without `@`, or a `UC...` channel ID), `channel_videos` (`handle`; optional `sort`: `latest`, `popular`; `cursor`).
- **Reddit** (`reddit`): Public Reddit data. `action` (required): `search` (`query`; optional `sort`: `relevance`, `new`, `top`, `comment_count`; `timeframe`: `all`, `day`, `week`, `month`, `year`; `cursor`), `subreddit` (`name`, case-sensitive, such as `AskReddit`), `subreddit_posts` (`name`; optional `sort`: `best`, `hot`, `new`, `top`, `rising`; `timeframe` for `top`; `cursor`), `post` (`id`: post ID or URL), `comments` (`post_id`; optional `cursor`; a tree with the replies Reddit loaded).
- **Threads** (`threads`): Public Threads data. `action` (required): `search` (`query`; optional `start_date`, `end_date` as YYYY-MM-DD; one page), `search_users` (`query`: a username or name), `profile` (`username`), `profile_posts` (`username`; the latest posts only), `post` (`id`: post URL or shortcode; includes replies and the author's thread continuation). Threads returns one page: no action takes a cursor.
- Paging for `tiktok`, `facebook`, `instagram`, `youtube`, and `reddit`: list actions return `results` and `next_cursor`. For the next page, call the same action with the same target and `cursor` set to `next_cursor`, unchanged. `next_cursor` is null on the last page; a cursor lasts 24 hours.
- **People Search** (`people-search`): Start a billed background search for people who match a plain-language description. It reserves `count` people at the platform's per-person price and bills only the people it delivers; a search that finds no one is free. Arguments: `platform` (required: `x`, `youtube`, `linkedin`, `tiktok`), `query` (required), `count` (optional, 5 to 200), `min_score` (optional, 0 to 100), `exclude` (optional handles), `metadata` (optional labels such as `{"campaign": "q4-outbound"}`: up to 10 keys of a-z, 0-9, `_`, `.`, `-`, string values up to 200 characters; returned on the task), `idempotency_key` (optional; reuse it on a retry so the search is not started twice). Filters by platform: x `min_followers`, `max_followers`, `verified_only`, `countries`, `keywords`, `exclude_keywords`; youtube `min_subscribers`, `max_subscribers`, `countries`, `require_contact`, `keywords`, `exclude_keywords`; linkedin `min_followers`, `max_followers`, `countries`, `keywords`, `exclude_keywords`; tiktok `min_followers`, `max_followers`, `require_contact`, `keywords`, `exclude_keywords`.
- **People Search Status** (`people-search-status`): Status, progress, cost, and a page of people for one task. Searches usually take 1 to 5 minutes. Arguments: `task_id` (required), `cursor` (optional, the previous `next_cursor`, to get only new people), `limit` (optional, 1 to 100, default 25), `include_people` (optional).
- **Pause People Search** (`people-search-pause`): Pause a task. Argument: `task_id` (required).
- **Resume People Search** (`people-search-resume`): Resume a paused task with no new charge. Argument: `task_id` (required).
- **Cancel People Search** (`people-search-cancel`): Stop a task for good; only people already delivered are billed. Argument: `task_id` (required). Cancel cannot be undone.
- **List People Search Tasks** (`people-search-tasks`): Your searches, newest first. Arguments: `platform`, `status` (list), `limit`, `cursor`, `metadata` (up to 3 labels a task must have, exact match), all optional.
- **List People Found** (`people-profiles`): Everyone your searches found on one platform. Arguments: `platform` (required), `q`, `sort` (`score`, `recent`, `audience`), `limit`, `cursor`, `has` (list of `email`, `website`, `x`, `linkedin`, `instagram`, `youtube`, `tiktok`), `min_audience`, `max_audience`, `min_score`, `location`, `verified`.
- **Export People Found** (`people-search-export`): The people found as CSV or JSON Lines text, after a note with the row count. Arguments: `task_id` (one search) or `platform` (everyone found there), `format` (`csv` or `jsonl`), the `people-profiles` filters, and `max_rows` (1 to 1000, default 100). Free.
- **Company Search** (`company-search`): Start a billed background task that finds companies on the web matching a plain-language description and collects each one's public emails, phones, social profiles, and leaders (with LinkedIn profiles and emails). It reserves `count` companies at the Company Search price and bills only the companies it delivers (a minimum of 2 when it delivers any; a task that delivers none is free). Arguments: `query` (required, 3 to 1000 characters), `count` (optional, 5 to 200, default 25), `min_score` (optional, 0 to 100), `exclude` (optional domains or URLs, up to 1000), `countries` (optional ISO codes or names, up to 20), `require` (optional list of `email`, `phone`, `linkedin`, `leader`, `leader_email`; a company without them is not delivered or billed), `roles` (optional list of `ceo`, `founder`, `cto`, `cfo`, `coo`, `cmo`, `president`, `owner`, `managing_director`; default `ceo`, `founder`, `cto`, `cfo`), `infer_emails` (optional, default true), `verify_emails` (optional, default true), `metadata` (optional labels, same rules as People Search), `idempotency_key` (optional).
- **Company Enrich** (`company-enrich`): Start a billed background task that collects the same public contact data for companies you already know. One company per domain, with no fit score (`score` is null). It reserves one company per domain sent at the Company Enrich price and bills only the companies it delivers (a minimum of 1). Arguments: `domains` (required, 1 to 200 domains or URLs; deduplicated), `roles`, `infer_emails`, `verify_emails`, `metadata`, `idempotency_key` (all optional).
- **Company Search Status** (`company-search-status`): Status, progress, cost, and a page of companies for one Company Search or Company Enrich task. Companies arrive with `enrichment` status `partial` and later stages fill them in: pass the previous `next_cursor` as `cursor` to get only new companies, and call without `cursor` to read every company in its latest version (do that once more after the task is done). Arguments: `task_id` (required), `cursor` (optional), `limit` (optional, 1 to 100, default 10), `include_companies` (optional).
- **Pause Company Search** (`company-search-pause`): Pause a task. Argument: `task_id` (required).
- **Resume Company Search** (`company-search-resume`): Resume a paused task with no new charge. Argument: `task_id` (required).
- **Cancel Company Search** (`company-search-cancel`): Stop a task for good; only companies already delivered are billed. Argument: `task_id` (required). Cancel cannot be undone.
- **List Company Search Tasks** (`company-search-tasks`): Your Company Search and Company Enrich tasks, newest first. Arguments: `type` (`search` or `enrich`), `status` (list), `limit`, `cursor`, `metadata` (up to 3 labels a task must have, exact match), all optional.
- **Create Monitor** (`monitor-create`): A search over `web`, `x`, `reddit`, `youtube`, `threads`, `tiktok`, and `meta_ads` (Meta Ad Library ads; write the query as keywords) (or up to 10 watched accounts per source and up to 10 TikTok or Instagram hashtags; `instagram` and `facebook` only watch accounts or hashtags and need `instagram_accounts` or `instagram_hashtags`, or `facebook_pages`) that reruns every `interval` (`1h`, `3h`, `6h`, `12h`, `1d`, `7d`) and keeps only new items that pass the screen (relevant, new information, and each criterion; kept at `min_score`, default 60). Creating it is free; each run is billed when it ends (its searches at list price, AI screening at $0.05 per 1,000 items screened, the summary's LLM usage plus 50%), and `run_now` (default true) queues the first run at once. Arguments: `query` (required, 3 to 500 characters), `name`, `criteria` (up to 5), `sources`, `interval`, `web_count` (10, 15, 20), `x_count` (1 to 100), `x_lang`, `x_min_likes`, `x_accounts`, `reddit_subreddits`, `youtube_channels`, `tiktok_accounts`, `tiktok_hashtags`, `threads_accounts`, `instagram_accounts`, `instagram_hashtags`, `facebook_pages` (up to 10 each; a hashtag (`skincare`, `#სილამაზე`, or a tag URL) finds posts from any account; the query and criteria still decide what is kept, `min_score` 0 keeps every new post; TikTok search has no date filter and ranks by relevance, so watch `tiktok_accounts` to follow creators), `tiktok_count` (10, 20, 30), `meta_ads_count` (10, 20, 30), `min_score`, `summary`, `webhook_url`, `webhook_events`, `metadata`, `run_now` (all optional). With `webhook_url` the reply has `webhook_secret`, shown only once.
- **Estimate Monitor Cost** (`monitor-estimate`): The most one run and one month can cost. Arguments: `sources`, `web_count`, `x_count`, the watched-account lists, `tiktok_count`, `meta_ads_count`, `summary`, `interval` (all optional). Free.
- **List Monitors** (`monitor-list`) and **Get Monitor** (`monitor-get`): Your monitors (`status`, `limit`, `cursor`) or one monitor (`monitor_id`), with status, `next_run_at`, `last_run`, and totals. Free.
- **Update Monitor** (`monitor-update`): Change settings, pause (`status: "paused"`) or resume (`"active"`), or `remove_webhook`. Arguments: `monitor_id` (required) and what to change. Per-source options replace the old ones as a whole. Free.
- **Delete Monitor** (`monitor-delete`): Delete a monitor for good. Argument: `monitor_id` (required). Free. To stop it for a while, pause it instead.
- **Run Monitor Now** (`monitor-trigger`): Queue one billed run now. Argument: `monitor_id` (required).
- **List Monitor Runs** (`monitor-runs`) and **Get Monitor Run** (`monitor-run`): Runs with per-source stats and cost (`monitor_id`, `limit`, `cursor`), or one run with the items it kept (`monitor_id`, `run_id`). Free.
- **List Monitor Items** (`monitor-items`): Everything a monitor kept, newest first. Arguments: `monitor_id` (required), `source`, `limit` (1 to 200), `cursor`. Free.
- **Test Monitor Webhook** (`monitor-webhook-test`) and **Rotate Monitor Webhook Secret** (`monitor-webhook-rotate-secret`): Send a signed test event, or replace the signing secret (the new one is shown once). Argument: `monitor_id` (required). Free.

Before `people-search`, check `people-profiles` when the user may already have searched for these people. Start a new search only when the user asks to find people. Use `company-search` only when the user asks to find companies, and `company-enrich` when they already have the domains; both are billed. A People Search `task_id` does not work on the company tools, and a company `task_id` does not work on the People Search tools. Use `monitor-create` only when the user asks to keep watching a topic, because every run is billed; `monitor-estimate` says what it will cost first.

## When not to use these tools

Skip Desearch when the task is only about files in the current project, or when the text you need is already in the conversation. These tools do not browse a logged-in site, post to X, contact the people or companies they find, or change Desearch account settings.
